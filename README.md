## 制作方式

- 动画全部以 React 组件编写，按帧渲染输出，每个知识点对应一个独立场景组件；
- 旁白由语音合成生成，字幕与旁白逐句锚点对齐；
- 每部成片经关键帧视觉审查、分段拼接边界连续性校验与音频电平核验后交付。
